# 🪄 Hogwarts War

**A magical battle. A personal journey. A project reborn.**

Hogwarts War is a pixel-art browser game inspired by an original Python text-based game I created during my second year of high school as my graduation project for the Digital Egypt Cubs Initiative (DECI).

The original project received a full mark, and its concept, storyline, and code were developed entirely without AI assistance.

Years later, during my third year at university, I decided to revisit the idea and transform it into a playable game with graphics, animations, sound effects, music, and interactive battles.

The result is a new version of a project that has grown alongside me.

## ✨ Features

- **Pixel-Art Graphics:** A dark, atmospheric Hogwarts-inspired battlefield.
- **Animated Characters:** Moving characters, spell projectiles, and visual effects.
- **Synthesized Audio:** Background music and sound effects generated directly in the browser.
- **Interactive Battles:** Choose spells strategically to defeat your enemies.
- **Hogwarts Houses:** Begin your journey with a randomly assigned Hogwarts house.
- **Boss Fights:** Face Bellatrix Lestrange and Lord Voldemort.
- **Game Mechanics:** Health points, defensive shields, enemy health bars, and replay options.
- **Responsive Interface:** Designed to work across different screen sizes.
- **Progressive Web App Support:** Includes PWA-related configuration for supported browsers.

## 🧙 Gameplay

Your journey begins at Hogwarts, where the Sorting Hat assigns your house. Soon after, the castle comes under attack.

Choose your spells carefully, defend yourself, and defeat increasingly dangerous enemies. Some spells can cost you a life, while others can lead you toward victory.

Your goal is to defend Hogwarts without using the Unforgivable Curses.

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- HTML Canvas API
- Web Audio API

The game runs in a modern web browser without requiring a JavaScript framework or external game engine.

## 🚀 How to Run

1. Download or clone this repository.
2. Extract the ZIP file if you downloaded the archive.
3. Open the project folder.
4. Run `index.html` using a local development server for the best experience.

For example, if you have Python installed, open a terminal in the project folder and run:

```bash
python -m http.server 8000
```

Then visit:

`http://localhost:8000`

If the `python` command does not work on Windows, try:

```bash
py -m http.server 8000
```

A local server is recommended because the project includes a service worker and PWA configuration.
